01切块 · 示意图 · 输入是一张猫图

语言模型只认 token：先把图切成小块，一块一个

浅色格线是切块边界（这里画成 8×8 示意）；橙框是其中一块，它会变成一个 token
按 14 像素切，448×448 的图是 32×32 = 1024 块。块切得越小，细节越多，但 token 也越多——下一段就卡在这里。
01切块 · 左：照片 · 右：同一只猫的 CG 渲染

同一只猫，照片和渲染差在纹理

看毛发：左边一根根有方向，右边是平滑色块；切成小块后，这种差别就落在每一块的局部纹理上
两图并排是为了对照，讲稿只说差在哪、为什么差；两张图各自是什么，kicker 和 sub 已经说了。
02合并 · 自绘 · 数字按 448×448 输入算

要把图送进语言模型：先减数量，再换空间

从左往右是一张图进模型的路；橙框是这页的主角——合并器，块下的数字是这一步之后的 token 数或维度
目的是让语言模型能读图，但卡在两处：① 注意力成本随 token 数平方涨，1024 个太多；② 视觉特征的维度和空间都和语言模型不一样。所以先 2×2 合并减到 256 个，再用 MLP 换到语言模型的维度。

合并越狠越省，但一个 token 要装的像素越多
