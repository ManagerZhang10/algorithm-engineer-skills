# 样式规则

`figlib.py` 已经按这些规则实现，平时不用手写样式。需要改配色、新增元素、或者脱离 figlib 手写 draw.io XML 时读本文件。
所有颜色和字体都是**可替换的默认值**：改 `figlib.PALETTES` / `figlib.FONT` 即可。

## 画布与三段

- 白底，无网格，无页面边界。默认画布约 1460 × 740。
- 左段「整体」不加框；中段「一个 block」用主面板（黑边 2px、底色 #F8F8F8、arcSize 3）；
  右段「独有做法」用次面板（灰边 #9A9A9A、底色 #F5F5F5）。
- 放大关系用虚线（6 5，无箭头，#555）：上线从被放大块右上角连到中段面板左上角；
  下线从右下角连到面板左边、比块底低约 44px 处。**不要连到面板底角**，那条线会穿过左段输入 lane 的文字。
- 每段底部一行 15px 深色说明，居中。右段底部一行 9.5px 灰字写出处（仓库 @ commit · 文件:行号）。

## 块

- 一律圆角（arcSize 18）、无描边，只靠淡色填充区分语义。
- 字体默认 `PingFang SC, Helvetica`。块内主文字 13–14px #333；副标题另起一行，小 3px，#777。
- 强调块（当前讲的核心，如注意力）加粗并用同色系深一档。
- **蓝框 = 这个模型独有的做法**（2.2px #0071E3）。两套配色都遵守，图例写在页面或 deck 的 kicker 里。

## 配色（paper，默认）

| 语义 role | 填充 | 用在 |
| --- | --- | --- |
| `io` | #E4E4E4 | 输入、输出、张量、中性步骤 |
| `norm` / `inject` | #CFE0F7 | 各种 Norm；从侧面注入的 mask、位置编码 |
| `cond` / `mod` | #E2D3F5 | 时间步、条件、调制（Scale & Shift、Gate）、Router |
| `attn` | #FDE6C6 | 注意力子层的线性层、QK-Norm、RoPE |
| `core` | #F7C57A | 核心注意力本身，配合加粗 |
| `ffn` | #C8E6C4 | FFN、专家、输出头 |
| `seg_txt` / `seg_ref` / `seg_x` | #D9D9D9 / #CFE0F7 / #E2D3F5 | 序列条里的文字段 / 参考图段 / 目标段 |
| `white` | #FFFFFF | 大 block 框（配黑边）、虚线容器 |

`deck` 配色把以上填充全部换成 #F5F5F7（core 用 #E8E8ED），蓝框块再填 #E8F0FE、文字变蓝。
默认用 paper：五色能让 block 内部一眼分层；只有整套 deck 必须严格单色时才用 deck。

## 连线

- 直线（edgeStyle=none），1.4px，实心小三角箭头。paper 用 #333，deck 用 #8E8E93。
- 主干一律竖直向上。一根线分给两个目标时从源块顶边不同位置出发，不画斜向交叉。
- 残差：从输入块顶边上方分出，沿主干外侧约 16px 竖直上行，水平进入 ⊕ 的侧边。⊕ 是白底黑边圆，半径 11。
- 调制总线（t 从哪里进）：灰色 #9A9A9A、1.2px，从左下角的调制源块出发，沿残差再外侧上行，
  逐个水平箭头进入 Scale & Shift / Gate 块。双流 block 两侧各一条。
- 侧向注入（mask、位置编码）：注入块放主干右侧，水平箭头进入目标块右边中点；说明文字放注入块正下方。

## 批注

- 面板内解释文字 10.5–12px 灰字。关键否定（「无 adaLN」「没有 shift」）放中段右上角，12px 加粗，
  paper 用橙 #E8931D，deck 用蓝。

## 字号底线

图最终的显示宽度决定字号。`archfig build --fit-width <px>` 会报告缩放后的正文字号：

| 用途 | 显示宽度 | 缩放后正文 |
| --- | --- | --- |
| 1920×1080 slide，图全宽 | 约 1664px | 约 15px，勉强 |
| slide 左图右注释（图占 2/3） | 约 1070px | 约 9.5px，太小 |
| 竖屏 1080 宽 | 约 1000px | 约 9px，太小 |

所以三段图放进 slide 时，**拆成两页**（整体 + block 一页，独有做法一页）或整页全宽不放注释；
不要塞进左图右注释的版式。
